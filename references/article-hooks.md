# 长文开头扩展

用户要 Article、教程或完整导入段时，沿用 [情绪机制](hook-patterns.md)，把第一眼的反差接到文章要交付的内容。用户只改开头时别重写正文。

常见衔接：

- 复盘：具体结果或认知变化 → 最难的一步 → 后文展示过程。
- 教程：具体麻烦 → 能省去的动作 → 演示第一步。
- 观点：强判断 → 反常现象 → 解释判断依据。
- 资源分享：难得公开的部分 → 读者怎么使用 → 材料在哪里。
- 失败经历：现场崩溃 → 具体代价 → 哪个环节出了问题。

别强制“三个问题目录”。只有后文确实分三部分且用户要完整导入时，目录才有用。开头已经有清楚的阅读理由，就直接进入正文。
