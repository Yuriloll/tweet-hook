# Hook Patterns Reference（推文开头类型库）

多 AI 通用。生成前快速对照。模板里 `{ }` 为可替换槽位。  
无 X 检索时也可只靠本文件 + `swipe-openers.md` 出合格开头。

---

## 1. 制造矛盾（Contradiction）

**机制：** 两个信念互相打架 → 大脑必须停下来和解。

| 骨架 | 示例方向 |
|------|----------|
| `{常识} 是错的。真正决定 {结果} 的是 {反常识}` | 努力≠结果 |
| `我花了 {代价} 才发现：{A} 和 {B} 不能同时成立` | 取舍 |
| `{人群} 都在追 {热}，赢家却在做 {冷}` | 反向 |
| `不是 {表面原因}，是 {刺耳真相}` | 重归因 |
| `{成功符号} 越标准，{失败} 越隐蔽` | 反鸡汤 |

**信号词：** 但、其实、相反、你们搞反了、越…越…

---

## 2. 制造焦虑（Anxiety / Cost of inaction）

**机制：** 暗示「你已经落后 / 窗口在关 / 有隐性代价」。

| 骨架 | 示例方向 |
|------|----------|
| `还在 {旧做法} 的人，会在 {时间} 后付出 {代价}` | 时间窗 |
| `{数字}% 的 {人群} 不知道：{隐患}` | 统计压迫感（需真实或标注来源） |
| `你以为在 {进步}，其实在 {空转}` | 伪努力 |
| `{一次选择} 会在 {周期} 后复利成 {差距}` | 复利恐惧 |
| `别等 {事件} 发生再学 {技能}` | 预演痛苦 |

**边界：** 揭示代价可以；恐吓诈骗、虚假限时、仇恨煽动不要。

---

## 3. 制造话题（Topic / Stance）

**机制：** 强迫站队或给现象命名 → 评论区开战/补枪。

| 骨架 | 示例方向 |
|------|----------|
| `{阵营A} 和 {阵营B} 吵的不是 {表面}，是 {本质}` | 重新定义战场 |
| `我给这种现象取名：{新词}` | 命名权 |
| `支持 {观点} 的人，通常已经 {身份特征}` | 身份挂钩 |
| `别再问 {烂问题}。该问的是 {好问题}` | 议程设置 |
| `{热点} 撕开的是 {长期矛盾}` | 借势升维 |

---

## 4. 制造热度（Heat / Proof / Spectacle）

**机制：** 结果、数字、戏剧性、权威背书 → 立刻觉得「有料」。

| 骨架 | 示例方向 |
|------|----------|
| `{周期} {结果数字}：我只做了 {反直觉动作}` | 结果前置 |
| `{名人/公司} 公开做了 {事}，说明 {判断}` | 借势 |
| `一条 {内容} 带来 {指标}，拆开头 3 秒` | 案例 |
| `从 {0} 到 {1} 的关键不是 {工具}，是 {决策}` | 路径反转 |
| `今天 {圈内} 都在转的点：{一句话}` | 现场感 |

**规则：** 数字优先用用户自己的真实数据；禁止虚构「十万粉一夜」。

---

## 5. 制造好奇（Open loop / Curiosity）

**机制：** 信息缺口 — 知道「有答案」但答案在后面。

| 骨架 | 示例方向 |
|------|----------|
| `先说结论：{炸裂结论}。原因只有一个。` | 结论钩 |
| `三个 {错误/信号}，第 2 个最贵` | 列表钩 |
| `别划走：后面有 {可复制模板/清单}` | 利益钩 |
| `我后悔没在 {时间点} 明白这件事：` | 叙事钩 |
| `如果你也 {痛点}，看完这帖能省 {代价}` | 对号入座 |

**注意：** 钩子后第一句必须开始兑现，否则掉信任。

---

## 6. 组合拳（高转化常见）

爆款开头经常是 **2 型叠加**，例如：

- **矛盾 + 热度：** `月入{X}后我才敢说：{常识}是错的`
- **焦虑 + 好奇：** `还在{旧方法}？你可能正在付出{代价}。判断方法如下`
- **话题 + 矛盾：** `{阵营}赢了舆论，输了{实质}`

组合必须来自同一组已提取事实，不能为了叠加类型增加数字、因果或结果。

## 7. 五步诊断到钩子类型

先完成 `SKILL.md` 的 Hook Brief，再选择句式：

| Hook Brief 字段 | 优先类型 | 选择条件 |
|-----------------|----------|----------|
| 目标读者 + 当前最痛点 | 焦虑 / 好奇 | 痛点具体，读者能对号入座 |
| 最反常识观点 | 矛盾 / 话题 | 原内容确实支持该判断 |
| 最具体数字/结果 | 热度 / 矛盾 | 数字有对象、周期、口径和来源状态 |
| 最强好奇心句 | 好奇 | 后文有明确答案，下一句能开始兑现 |

某字段为 `缺失` 时跳过对应类型。某字段为 `推断` 时降低表达强度，不把推断写成事实。

---

## 8. 质量自检（发布前 8 问）

1. 目标读者能否立刻判断这条内容与自己有关？
2. 痛点是否具体到一个场景、障碍或代价？
3. 反常识观点是否来自原内容，而非模板制造？
4. 数字或结果是否保留了对象、周期、口径与证据状态？
5. 信息缺口能否在下一句开始兑现？
6. 去掉所有形容词后是否依然成立？
7. 是否像广告口号、虚假限时或绝对承诺？
8. 是否暗示并不存在的观察、测试、因果或影响？

## 中文节奏提示

- 前 **12–20 字** 出冲突，逗号后再补信息。  
- 少用「赋能、闭环、底层逻辑」开场（易滑走）。  
- 口语 > 论文体；可断句、可单行。  
- 一句一个爆点，不要开头塞三个论点。
