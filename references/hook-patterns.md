# 情绪机制：把读者的反应拉起来

语气以 [用户五个原始案例](priority-templates.md) 为基准。下面的机制帮助找到不同的狠法：兴奋、贪心、不服、危机感、逆袭欲望、当场破防，都可以成为第一句。

## 14 个切口

| 切口 | 第一眼的刺激 | 怎么往下推 |
|---|---|---|
| 苦活消失 | 终于不用再受这个罪了 | 从一个烦人步骤推到整套工作方式 |
| 预期被打穿 | 连这都能做？ | 小预期撞上大结果，接震惊或认错 |
| 小输入大产物 | 一句话干出整套东西 | 把输入与产出的体量放在同一行 |
| 底牌公开 | 连这也舍得往外放？ | 成品只是开胃菜，制作过程才值钱 |
| 投入失衡 | 这么点东西折腾死我 | 时间、金钱、返工量与产物直接相撞 |
| 宣传打脸 | 吹得这么狠，结果就这？ | 冲突前置，让反讽和不服气带着读者往下走 |
| 迟到领悟 | 前面那堆力气可能白花了 | 先说醒悟，再揭真正决定结果的一步 |
| 情绪反转 | 坏事来了，我反而爽了 | 把反常态度写在前面，引出背后原因 |
| 身份跃迁 | 我这种人也能上桌了 | 普通起点与高门槛成果同屏 |
| 愿望实现 | 这画面谁不想给自己整一个？ | 把功能放进婚礼、作品、事业等具体场景 |
| 一步翻盘 | 改这一下，整个流程顺了 | 小动作带出一连串收益 |
| 反向选择 | 看完 A，反而更想用 B | 先给出意外决定，后面解释关键发现 |
| 成绩爆发 | 终于把这个数干出来了 | 庆祝、炫耀、复盘连起来 |
| 生意机会 | 这东西都有人付钱了？ | 从产品功能推到需求、交付、复制与收入 |

这些切口可以叠加。比如“一句话做成视频”叠加“一个人顶一个制作团队”；“普通人做出 App”叠加“专业门槛被撞开”。

## 三段推进

**先炸一下 → 把反差砸出来 → 把利害推给读者。**

以“Codex 做视频”为创作主题：

- 起势：Codex 这次真杀疯了。
- 反差：以前写稿、切片、加字幕来回折腾，现在整条线直接接起来。
- 利害：一个人把这串活包圆之后，做内容的玩法真得重新算了。

也可以第一句就把反差塞进去：“一句话丢给 AI，后面站起来一整支制作队。”用户喜欢的是这种能力突然放大的感觉。

## 声量与措辞

默认使用高强度版本。“卧槽、杀疯、端了、坐不住、干服了、掀桌子、上头、门槛被撞开、好日子到头了”都是可用的表达资源。

大判断负责停滑，具体动作负责画面，第二句负责情绪升级。可以先宣判，再讲经历；先亮结果，再补过程；先制造危机，再递给读者一个可行动的方向。

只有用户主动要求克制时才降低声量。表达自然比机械堆叠更重要；六条候选可以分别用狂喜、破防、宣判、逆袭、赚钱与揭秘的方式发力。

## 对照校准

| 偏温和的表达 | 本版追求的力度 |
|---|---|
| 这个工具提高了工作效率 | 我靠，这工具直接把我最烦的那串活接走了。 |
| 一个普通人也能制作应用 | 以前连代码都不敢碰的人，现在敢直接做 App 了。这门槛真给撞开了。 |
| 自动化可能改变工作方式 | 还靠这堆重复劳动堆人头的，真该重新算账了。 |
| 这份资料值得学习 | 连制作底牌都放出来了，这也太舍得了。 |
| 这个方向值得探索 | 机会都摆到眼前了，我现在只想知道第一步怎么干。 |

上面的强句是创作表达示范。先把候选写到这个幅度，再根据主题和用户反馈打磨。
