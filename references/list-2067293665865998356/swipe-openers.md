# 跨账号：五类开头规律（本列表实测）

## 1. 制造矛盾
- 伪命题打脸：`找不到选题是伪命题`
- 排比反转：`最…的人，竟然…`
- 行业打假：`不要再相信一键…`
- 策略对偶：`流媒体止损 vs AI 上最贵`

## 2. 制造焦虑
- 额度/封号/下架/用量不清
- 模型太多任务不够（自嘲）
- 赛博病、成瘾症状
- 劝退：`别碰 AI 短剧流水线`

## 3. 制造话题
- `我单方面宣布…前三`
- 点名最强选手 / 变现名单
- 多方官宣拼贴（马/奥/安/谷）
- 升维：`大厂抢的是控制权`

## 4. 制造热度
- 结果前置：`冷启动必过万粉` `月入23w` `引流款200万`
- 成品视频/网站 demo 标题即钩
- 星数、分钟数、SOTA、美元成本
- `卧槽` / `魔法` / `过年了`

## 5. 制造好奇（信息缺口）
- 七字判决 + 图
- `下周末公开` / `说多了砸饭碗`
- `一个人名顶十万字提示词`
- 时间轴目录：`1:30 规划… 2:26 构建…`
- `氪金玩家滑走`（反向筛选）

# 生成时默认组合（适配本列表读者）

优先用 **2 型叠加**：

| 目标 | 组合 | 例骨架 |
|------|------|--------|
| 涨粉讨论 | 话题站队 + 矛盾 | 我单方面宣布…其实真正赢的是… |
| 收藏转发 | 热度数字 + 列表 | 刚发现 N 个…必备 |
| 树立认知 | 刺耳矛盾 + 重定义 | 所谓 X 都是伪命题，真问题是 Y |
| 卖课/咨询 | 结果 + 半藏 | 我用…做到…，路径不展开，但… |
| 产品/开源 | 代价 + 交付 | 花了 N 小时试完，开源终极版 |

**少用：** 纯官方 PR 句（Introducing…）、空洞「赋能闭环」、无数字无冲突的「分享一下我的看法」。
