# Official / mega-brand openings（对照，少学）

列表内常见官方号（如 @OpenAI）高赞开头特征：

- `Introducing {Product}…`
- `Meet {Person}. A {role} doing {task} with {model}.`
- `GPT-x is available starting today…`
- 指标堆砌：SOTA、分数、plans 列表

**个人博主不要照抄**，除非你在做品牌官号。  
个人号应把官方新闻 **转译** 成：

- 情绪：`卧槽 / 过年了 / 愈演愈烈`
- 用户利益：`用量怎么算 / Plus 会不会秒空`
- 站队：`我单方面宣布…`
- 行动：`不知道干嘛就复刻网站`

见 `swipe-openers.md` 中 @xiaohu / @Saccc_c 的二创开头。
