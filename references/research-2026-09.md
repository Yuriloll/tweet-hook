## 采集方式与边界

- 6551：使用本机 opentwitter skill 对应的 6551 API，取得阿杭 50 条七月推文。随后接口报额度不足；余温只有资料，没有取得推文。没有把 REST 调用冒称为 MCP 成功调用。

- 检索格式：`from:账号 since:月起 until:下月起 -filter:replies -filter:retweets`。三月从 11 日开始，九月至采集时。按原帖 datetime 的 UTC 日期归月，搜索返回跨月项时不沿用查询标签。
- 本次是逐月热门抽样，辅以阿杭七月的 API 返回，七月明显较多；不是半年全集、随机抽样或账号风格频率统计。没有翻完所有月份全部结果。
- 取作者自己的起句，引用卡片不当成本人起句；没取到文字的文章卡片、纯链接不生成摘录。部分正文截断，仅分析可见起句及必要上下文。
- 浏览器互动为 2026-09-11（北京时间）观察值，只保存喜欢和观看。6551 整批字段为零，统一记为不可用；不与浏览器数字拼成涨幅。
- 按 ID 去重，近似句式仍保留原帖 ID，但做机制归纳时合并。商业推荐、反讽、争议和普通推荐是不同语境。

## 这批材料支持什么结论

可提炼的是情绪如何起、对象何时出现、反差怎样建立、下一句怎样承接。它不能证明一个开头带来了多少流量，也不能验证原帖中的营收、产品功能、模型排名或预测。

阿杭样本里较鲜明的是现场反应、投入失衡与经历后的认知变化；余温样本里较鲜明的是惊喜到读者利益的转换，以及小输入与大结果的对照。两人都存在温和、直给的起句，不能简化成“粗口越多越好”。这些是本次阅读判断，不是训练模型或量化风格分类。

案例优先选：起句可读、情绪或对照明确、不同月份都有、不同机制可迁移；保留几条温和或普通推荐作对照。没有因为高互动就自动入选，也没有因为低互动就丢掉鲜明表达。
